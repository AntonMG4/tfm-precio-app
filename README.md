# Recomendador de precio — Airbnb

App del TFM (Máster en Data Science y Big Data, Universidad de Sevilla): a
partir de los datos de un alojamiento nuevo, recomienda un precio con su
rango de confianza y explica qué características lo justifican, usando el
modelo XGBoost entrenado en `TFM_ModeloPrecio.qmd`.
